# Luján Márquez HR

Sitio web institucional para **Luján Márquez Recursos Humanos**, orientado a presentar servicios de asesoramiento profesional y preparación para la búsqueda laboral.

## Descripción

El sitio presenta los servicios ofrecidos por Luján Márquez HR, con una interfaz visual diseñada para comunicar su propuesta de valor y facilitar el contacto con potenciales clientes.

### Servicios

- **Confección de CV:** elaboración de currículums optimizados para sistemas de seguimiento de candidatos ATS, adaptados a la experiencia y las habilidades de cada persona.
- **Cartas de presentación:** preparación de cartas para acompañar postulaciones laborales y candidaturas espontáneas.
- **Asesoramiento personal:** preparación para entrevistas, análisis FODA y orientación para mejorar la presentación profesional.

También incluye información sobre los servicios, material gráfico promocional y enlaces a los canales de contacto.

## Tecnologías utilizadas

- HTML5 para la estructura del sitio.
- CSS3 para los estilos y la personalización visual.
- Bootstrap 5 para la maquetación y el diseño adaptable.
- Font Awesome para los iconos.
- Google Fonts para la tipografía.

## Instalación y ejecución

No requiere instalación de dependencias ni configuración de un servidor backend.

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/mati-romero/lujan-marquez.git
   ```

2. Ingresar al directorio:

   ```bash
   cd lujan-marquez
   ```

3. Abrir el archivo `index.html` en un navegador web.

También es posible utilizar la extensión Live Server de Visual Studio Code para visualizar los cambios durante el desarrollo.
